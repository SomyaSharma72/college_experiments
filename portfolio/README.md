# Experiment 2: Personal Portfolio

A responsive personal portfolio for Somya Sharma, with About, Skills, Projects, and Contact sections. The projects section is a Bootstrap carousel.

## Files

- `index.html` — portfolio content, Bootstrap layout and carousel, and Bootstrap Icons.
- `style.css` — colors, layout, and responsive styles.

## Run locally

Open `index.html` in a web browser. Keep `style.css` in the same folder. Bootstrap 5.3.3, Bootstrap Icons, and Unsplash images are loaded from CDNs, so an internet connection is needed for those assets.
