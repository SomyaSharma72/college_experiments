# Experiment 7: React Notes App

A single-page notes app built with React. Create notes, read them in the notebook, edit them, delete them, and search by title or content. Notes are saved in the browser with `localStorage`.

## Files

- `index.html` — app markup, React components, and note actions.
- `style.css` — responsive layout and visual styles.

## Run locally

Open `index.html` in a browser while connected to the internet. React and Babel are loaded from CDN links in the page. Notes are stored in that browser and are not shared across browsers or devices.
