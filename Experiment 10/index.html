Deployment checklist

  1. Netlify: deploy static-site as the site/publish directory in Netlify. No build command is required.
  2. AWS Elastic Beanstalk: in dynamic-site, run npm install, then create a Node.js environment and upload the folder contents as the application bundle.
  3. Use each platform's dashboard to confirm the public URL and review deployment logs.
