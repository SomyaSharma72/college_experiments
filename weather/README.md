# Experiment 5: Weather App

A city weather search using the Open-Meteo Geocoding API to find coordinates and the Open-Meteo Forecast API to retrieve current conditions.

## Files

- `index.html` — page structure, styles, and Fetch API code.

## Run locally

Open `index.html` in a modern browser with an internet connection. Enter a city and select **Search**. The app displays temperature, humidity, and wind speed, with messages for loading, unknown cities, and request errors.

No API key is required.
