# Experiment 1: Personal Profile and GitHub Pages

This experiment is a personal profile page with sections for background, skills, projects, and contact information. It also describes the GitHub workflow for publishing a static website.

## Files

- `index.html` — profile page and GitHub workflow instructions.

## Run locally

Open `index.html` in a web browser.

## GitHub workflow

Repository creation, commits, creating and pushing branches, reviewing and merging a pull request, and enabling GitHub Pages must be completed manually in Git and GitHub. The instructions on the page do not mean those actions have already been performed.
