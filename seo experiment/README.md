# Experiment 4: SEO and Accessibility

A student portfolio page demonstrating basic search metadata, semantic HTML, accessible navigation, keyboard focus styles, and responsive CSS.

## Files

- `index.html` — portfolio content, metadata, and navigation.
- `style.css` — page layout, responsive styles, and reduced-motion handling.

## Run locally

Open `index.html` in a web browser. Keep `style.css` in the same folder so the page styling loads.
