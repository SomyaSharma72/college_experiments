# Experiment 3: To-Do List

A small to-do app that lets you add tasks, mark them complete, undo completion, and delete tasks.

## Files

- `index.html` — page structure, styles, and JavaScript behavior.

## Run locally

Open `index.html` in a modern web browser. Enter a task and select **Add**. Use **Complete** to toggle its status or **Delete** to remove it.

Tasks are kept in the current page session and are not saved after the page is closed or refreshed.
