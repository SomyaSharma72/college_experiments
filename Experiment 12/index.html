A small board,
ready for the cloud.

This project combines React, Express, Node.js, and MongoDB. Start the local servers to use the task board, or follow the deployment guide to publish it on AWS Elastic Beanstalk with MongoDB Atlas.

Run it locally

  1. Install the root and client dependencies.
  2. Copy .env.example to .env and configure MongoDB.
  3. Run npm run dev:server and npm run dev:client in separate terminals.
  4. Open localhost:5173.
